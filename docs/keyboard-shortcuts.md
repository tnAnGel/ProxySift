# Горячие клавиши ProxySift

На macOS используйте `⌘`; на Windows и Linux — `Ctrl`.

## Навигация и проверка

| Сочетание | Действие |
| --- | --- |
| `⌘/Ctrl + 1` … `⌘/Ctrl + 8` | Обзор, проверка, источники, история, база прокси, база VPN, профили, ядра и GeoIP |
| `⌘/Ctrl + N` | Открыть страницу настройки новой проверки |
| `⌘/Ctrl + Enter` | Запустить или остановить проверку; в диалоге сохранить изменения или добавить источник |
| `⌘/Ctrl + F` | Сфокусировать поиск: на странице базы остаётся в текущей базе, в остальных разделах открывает поиск проверки |
| `⌘/Ctrl + Shift + E` | Экспортировать результаты проверки в CSV |
| `Esc` | Закрыть открытый диалог или меню; если они закрыты — остановить проверку |
| `⌘/Ctrl + Q` | Закрыть приложение |
| `F5` | Обновить состояние Xray и GeoIP на странице ядер и GeoIP |

## Источники

| Сочетание | Действие |
| --- | --- |
| `⌘/Ctrl + S` | Сохранить подписки и прокси-ссылки в диалоге редактирования; добавить источник в диалоге добавления |
| `Enter` | Добавить источник в диалоге добавления |

## Поля ввода

| Сочетание | Действие |
| --- | --- |
| `⌘/Ctrl + A` | Выделить всё |
| `⌘/Ctrl + C` | Копировать выделенное |
| `⌘/Ctrl + X` | Вырезать выделенное |
| `⌘/Ctrl + V` | Вставить из буфера обмена |
| `⌘/Ctrl + Z` | Отменить последнее изменение |
| `⌘/Ctrl + Shift + Z` или `Ctrl + Y` | Повторить отменённое изменение |
| `Tab` / `Shift + Tab` | Перейти к следующему или предыдущему доступному полю ввода |

## Справка

`F1` открывает или закрывает список сочетаний клавиш. Его также можно открыть через меню информации в правом верхнем углу окна.
