# Параметры проверки

На экране «Проверка» доступны лимит узлов, порог скорости, переключатель измерения скорости и GeoIP. В режиме HTTP / SOCKS остаются лимит и GeoIP; порог и измерение скорости относятся к VPN-проверке и для этого режима скрыты.

## Лимит

Лимит — максимальное количество уникальных прокси, которое приложение возьмёт в проверку после загрузки и разбора источников.

- Лимит **200** означает «проверить не более 200 узлов», а не «загрузить 200 источников».
- Некорректные строки и повторяющиеся узлы не увеличивают количество кандидатов.
- Если после разбора узлов меньше лимита, проверяются все найденные узлы.
- В VPN-режиме приложение перемешивает разобранный список и затем берёт первые N узлов. Поэтому при большом каталоге состав проверяемой выборки может различаться между запусками.
- В HTTP / SOCKS режиме лимит применяется к списку разобранных и дедуплицированных прокси.

Лимит должен быть целым числом больше нуля.

## Порог скорости

Порог — минимальная скорость передачи данных, необходимая VPN-узлу, чтобы пройти скоростную проверку. При включённом переключателе «Скорость» измерение выполняется через Xray.

Например, значение **100 КБ/с** означает, что узел должен показать не менее 100 КБ/с. Узел ниже порога не считается живым в итоговом VPN-результате и не попадает в файлы прошедших проверку узлов (`alive.txt` и `good.txt`). Чем выше порог, тем меньше узлов обычно пройдёт этот этап.

Доступны единицы **КБ/с** и **МБ/с**. При пересчёте приложение использует соотношение **1 МБ/с = 1024 КБ/с**. Так, порог **1 МБ/с** равен **1024 КБ/с**.

Если «Скорость» выключена, порог не применяется: приложение пропускает измерение через Xray и считает живыми узлы, ответившие на TCP-проверку. Порог не используется и в режиме HTTP / SOCKS.

## Переключатель «Скорость»

- **Включён** — после TCP-проверки приложение измеряет скорость VPN-узлов и применяет порог. Для этого нужен Xray Core; приложение проверяет локальную установку и при необходимости загружает компонент.
- **Выключен** — измерения скорости не выполняются. Проверка доступности по TCP остаётся включённой; порог игнорируется, а данные о скорости не рассчитываются.

Переключатель определяет глубину проверки, а порог задаёт минимальный результат для скоростного этапа.

## Переключатель GeoIP

- **Включён** — приложение определяет страну по IP-адресу узла через локальную базу GeoLite. Если базы нет, приложение подготавливает её перед проверкой.
- **Выключен** — проверка доступности продолжается, но страна не определяется и переименование узлов по GeoIP не выполняется.

GeoIP только добавляет сведения о стране; он не влияет на то, отвечает ли прокси и проходит ли он порог скорости.

## Пример с настройками на скриншоте

При **лимите 200**, **пороге 100 КБ/с** и включённых «Скорости» и GeoIP ProxySift:

1. Загружает и разбирает источники, удаляет дубликаты узлов.
2. В VPN-режиме перемешивает узлы и выбирает не более 200.
3. Определяет страны через GeoIP.
4. Проверяет доступность и измеряет скорость через Xray.
5. Считает прошедшими скоростной этап узлы со скоростью не ниже 100 КБ/с.

Эти значения соответствуют профилю **«Сбалансированный»**. Профили применяют настройки для следующего запуска:

| Профиль | Лимит | Порог | Скорость | GeoIP |
| --- | ---: | ---: | --- | --- |
| Быстрая проверка | 100 | Не используется | Выключена | Выключен |
| Сбалансированный | 200 | 100 КБ/с | Включена | Включён |
| Подробная проверка | 500 | 100 КБ/с | Включена | Включён |

Значения можно изменить вручную после применения профиля. Настройки сохраняются и используются при следующем запуске.
